# iPhone 6 (N61AP) fork notes

This fork builds on [CelestialSayuki/n56-patcher](https://github.com/CelestialSayuki/n56-patcher).
The original author developed the N56 iOS port, kernel adaptation framework and
installation workflow. This fork retains the original GPL-3.0 license and adds
the N61 changes described here.

## Status

An iPhone 6 (N61AP / iPhone7,2) completed the iOS 15.8.8 (19H422) slot install and
booted on 2026-11-23. This is a single-device installation and boot report, not a
claim that every hardware feature or another iOS version has been tested.

The existing target name `n56-ios15`, internal `n56/` input-cache directory and
patch IDs remain for compatibility. The verified donor's `N61.mtprops` selects
the native N61 resources; do not rename N61 firmware files to N56 filenames.

## Native adaptations

- N61 `tempranillo` Wi-Fi files and their three hashstore entries, retaining image verification.
- N61 multitouch personality and the native DeviceTree touch name.
- N61 model plists, audio tunings, ACT/MediaToolbox resources and thermal configuration.
- Native N61 camera plists and its AVGestalt device entry.
- The native N61 thermal class, product ID and two-word filter state.
- N61 Bluetooth product identity and the native 16H88 BlueTool.
- N61 motion-table entries and the donor's personalized Mav10 runtime firmware.
- Native-model-aware boot-package matching, donor snapshots and fresh input extraction.

## Inputs and preparation

Use the upstream macOS/Python environment setup and a native N61 iOS 12.5.8 SSH
ramdisk. Take and verify this device's donor snapshot before building. A snapshot
from a different device is not a substitute for its personalized firmware.

For fresh extraction, supply these IPSWs yourself under `ipsw/`:

```text
iPhone_4.7_12.5.8_16H88_Restore.ipsw
iPhone_5.5_15.8.8_19H422_Restore.ipsw
iPad_64bit_TouchID_15.8.8_19H422_Restore.ipsw
```

Full Xcode supplies the iPhoneOS SDK. A user-provided device SDK can also be
placed under `tools/sdks/` (the tested local fallback was `iPhoneOS15.6.sdk`).
SDKs, Apple firmware, generated boot images, device snapshots, APTickets, keybags
and device logs are not distributed by this fork.

Follow the upstream slot assignment and volume preparation workflow for
System15/Data15. The iOS 15 ramdisk connection in this fork uses port 2222.
`boot_ramdisk_n61.sh` is an optional uploader for an already-generated N61 ramdisk
under `tools/SSHRD_Script/sshramdisk`; it does not generate those images.

## Resume after the base-system transfer completed

If installation stopped during overlays, leave the phone in the SSH ramdisk and
run from the repository with the prepared Python environment:

```sh
sudo .venv/bin/python n56patcher.py slots resume 15
```

Resume verifies the selected System rootfs marker and build, builds the matching
boot package, continues overlay/finalize checkpoints, then records installation.
It does not wipe volumes or stream the base rootfs again. First keybag creation
requires a genuinely empty encrypted Data15 and is tied to its APFS UUID;
existing-data and recovery guards remain active.

Copied staged-app caches with absolute paths to another workdir are rebuilt from
the verified N66 source bundles and original Apple detached signatures. A damaged
same-location cache still fails validation.

After a successful installation, enter DFU and boot with:

```sh
sudo .venv/bin/python n56patcher.py slots boot 15
```

## Validation

The adaptation passed host tests, a complete five-IMG4 build, kernel unpacking
roundtrip checks, and inspection of the final N61 DeviceTree, touch personality,
Wi-Fi hashes, Bluetooth identity, thermal class and TrustCache inputs. The device
owner subsequently confirmed installation and boot.

Host checks that require a verified N61 donor can be enabled with:

```sh
N61_DONOR=/path/to/your/verified/snapshot \
  .venv/bin/python -m unittest patches.ios15.impl.test_n61_native
```

Use the upstream documentation for the original N56 workflow and technical
background. N61 changes here are maintained in this fork.
